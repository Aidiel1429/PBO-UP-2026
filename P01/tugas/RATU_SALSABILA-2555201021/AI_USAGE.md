# AI Usage

Dalam pengerjaan praktikum PBO ini, saya menggunakan bantuan AI sebagai pendamping dalam memahami materi dan beberapa bagian teknis.

AI membantu saya memahami konsep dasar Pemrograman Berorientasi Objek seperti class, constructor, property, dan method. AI juga membantu dalam memahami penggunaan Python, pytest, mypy, Git, dan GitHub.

Selain itu, AI membantu memberikan arahan ketika saya mengalami kesulitan dalam menjalankan program dan mengatur project. Setiap kode yang digunakan tetap saya jalankan dan periksa sendiri untuk memastikan program dapat berjalan dengan baik.

Penggunaan AI pada praktikum ini bertujuan sebagai alat bantu belajar agar saya lebih mudah memahami materi dan menyelesaikan tugas, bukan sebagai pengganti proses belajar dan pemahaman saya sendiri.
