# Penggunaan AI

Dalam pengerjaan praktikum PBO P03, saya menggunakan ChatGPT sebagai alat bantu belajar.

AI membantu saya memahami struktur program Python, memeriksa kemungkinan kesalahan pada kode, memahami pengujian program, dan mengikuti langkah penggunaan Git serta GitHub untuk mengumpulkan tugas.

Kode program tetap saya periksa dan jalankan kembali untuk memastikan program dapat berfungsi. Saya bertanggung jawab untuk memahami hasil pengerjaan dan menyesuaikannya dengan instruksi praktikum.

AI digunakan sebagai pendamping belajar, bukan sebagai pengganti proses memahami materi.
