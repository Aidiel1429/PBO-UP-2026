Refleksi P03 – Enkapsulasi

1. Hal yang Dipelajari

Pada pertemuan P03, saya mempelajari konsep enkapsulasi dalam Pemrograman Berorientasi Objek. Saya memahami bahwa enkapsulasi digunakan untuk melindungi data di dalam sebuah class agar tidak dapat diubah secara sembarangan. Saya juga mempelajari penggunaan property, setter, dan validasi data menggunakan ValueError.

2. Pengalaman Mengerjakan Tugas

Saat mengerjakan tugas P03, saya membuat beberapa class, seperti Alamat, Penyewa, AlatTani, dan Petugas. Saya juga membuat objek nilai menggunakan dataclass(frozen=True) agar data tertentu tidak dapat diubah setelah objek dibuat.

Selain itu, saya membuat pengujian menggunakan pytest untuk memastikan setiap class berjalan sesuai dengan ketentuan.

3. Kesulitan yang Dihadapi

Kesulitan yang saya alami adalah memahami cara kerja property dan setter, terutama dalam melakukan validasi ketika data dibuat maupun ketika nilainya diubah. Saya juga perlu memastikan bahwa setiap atribut memiliki aturan yang sesuai agar data tetap valid.

Untuk mengatasinya, saya mempelajari kembali materi, mencoba menjalankan program, dan memperbaiki kode berdasarkan hasil pengujian.

4. Kesimpulan

Dari tugas P03 ini, saya memahami bahwa enkapsulasi sangat penting untuk menjaga keamanan dan konsistensi data dalam program. Saya juga mendapatkan pengalaman dalam membuat class yang memiliki validasi data serta melakukan pengujian menggunakan pytest.

Saya berharap dapat menerapkan konsep enkapsulasi ini dengan lebih baik pada tugas-tugas berikutnya.
