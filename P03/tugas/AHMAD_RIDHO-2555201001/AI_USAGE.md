# AI Usage — P03

## Penggunaan AI

Saya memanfaatkan ChatGPT sebagai pendamping dalam mempelajari dan menyelesaikan Praktikum Pemrograman Berorientasi Objek (PBO) Pertemuan 3.

Bantuan AI digunakan untuk:
1. Memahami materi enkapsulasi, properti hanya-baca, validasi data, dan objek nilai (*value object*).
2. Membantu mengembangkan serta meninjau kode Python pada kelas `AlatTani`, `Penyewa`, dan `Petugas`.
3. Membantu menyusun pengujian menggunakan `pytest` untuk memeriksa data valid dan menolak masukan yang tidak sesuai.
4. Membantu memahami kesalahan program serta penggunaan mypy dan pemeriksa disiplin PBO.
5. Membantu menyusun dokumentasi praktikum dan memahami langkah pengelolaan tugas menggunakan Git.

## Tanggung Jawab

Saya bertanggung jawab untuk meninjau kode, menjalankan pengujian, memahami fungsi setiap bagian program, dan memastikan hasilnya sesuai dengan ketentuan praktikum.

AI digunakan sebagai sarana pendukung pembelajaran. Pemahaman terhadap kode dan hasil pengujian tetap menjadi tanggung jawab saya sebagai mahasiswa.
