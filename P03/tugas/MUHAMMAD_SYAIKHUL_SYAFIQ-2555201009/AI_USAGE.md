# AI Usage

## Penggunaan AI

Saya menggunakan ChatGPT sebagai alat bantu dalam proses pengerjaan tugas P03 tentang penjagaan atribut dan property dalam Pemrograman Berorientasi Objek.

### Bentuk bantuan AI

- Membantu memahami instruksi dan ketentuan praktikum P03.
- Membantu memahami property baca-saja dan setter dengan validasi.
- Membantu menyusun dan memeriksa kelas AlatTani, Penyewa, Petugas, Alamat, dan PeriodeTugas.
- Membantu menyusun pengujian menggunakan pytest, termasuk pengujian data tidak valid dan atribut yang tidak dapat diubah.
- Membantu menjalankan pemeriksa PBO, mypy, pytest, dan program utama.
- Membantu memberikan arahan penggunaan Git dan GitHub untuk pengumpulan tugas.

### Batas penggunaan

ChatGPT digunakan sebagai alat bantu untuk memahami materi, menyusun kode dan pengujian, serta menemukan kemungkinan kesalahan. Saya bertanggung jawab untuk mempelajari, memeriksa, memahami, dan mempertanggungjawabkan kode serta hasil tugas yang dikumpulkan.
