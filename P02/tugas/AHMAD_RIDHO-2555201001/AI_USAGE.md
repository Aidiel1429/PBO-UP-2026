# AI Usage — P02

## Penggunaan AI

Saya menggunakan ChatGPT sebagai alat bantu dalam mengerjakan Praktikum Pemrograman Berorientasi Objek (PBO) Pertemuan 2.

Bantuan AI digunakan untuk:
1. Memahami instruksi praktikum dan konsep kelas, objek, konstruktor, atribut, method, serta parameter `self`.
2. Membantu menyusun dan memeriksa kode Python untuk kelas `Penyewa`, `AlatTani`, `Keramba`, dan `Petugas`.
3. Membantu membuat pengujian menggunakan `pytest`.
4. Membantu memahami pesan kesalahan serta menjalankan pemeriksaan kode menggunakan mypy dan pemeriksa disiplin PBO.
5. Membantu memahami penggunaan Git untuk menyimpan dan mengumpulkan tugas.

## Tanggung Jawab

Saya tetap bertanggung jawab untuk memeriksa, menjalankan, memahami, dan memperbaiki kode yang digunakan dalam tugas. Hasil pengujian dijalankan pada lingkungan lokal saya.

AI digunakan sebagai pendamping belajar, bukan sebagai pengganti pemahaman terhadap materi praktikum.
