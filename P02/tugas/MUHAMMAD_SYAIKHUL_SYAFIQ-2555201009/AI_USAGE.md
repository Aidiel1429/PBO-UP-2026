# AI Usage

## Penggunaan AI

Saya menggunakan ChatGPT sebagai alat bantu dalam proses pengerjaan tugas P02.

### Bentuk bantuan AI

* Membantu memahami instruksi dan ketentuan praktikum P02.
* Membantu memahami penerapan konsep Pemrograman Berorientasi Objek pada pembuatan class `Penyewa` dan `AlatTani`.
* Membantu memberikan arahan dalam menyusun struktur file dan kode program.
* Membantu menjelaskan cara membuat dan menjalankan pengujian menggunakan `pytest`.
* Membantu memberikan arahan dalam penggunaan Git dan GitHub, seperti membuat branch, commit, push, dan pull request.
* Membantu memeriksa langkah pengerjaan dan memastikan struktur repository sesuai dengan ketentuan praktikum.

### Batas penggunaan

Kode dan tugas tetap saya pahami dan kerjakan sendiri. AI digunakan sebagai alat bantu untuk memahami materi, memberikan arahan, serta membantu mencari dan memperbaiki kesalahan selama proses pengerjaan. Saya tetap bertanggung jawab terhadap kode dan hasil tugas yang dikumpulkan.
