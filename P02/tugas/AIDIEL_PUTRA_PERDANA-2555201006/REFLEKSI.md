# Refleksi Pembelajaran - P02

### 1. Apa yang dipelajari?
Melalui tugas P02 ini, saya mempelajari penerapan konsep Pemrograman Berorientasi Objek (PBO) pada Python, khususnya dalam pembuatan class `Penyewa` dan `AlatTani`. Selain itu, saya juga memahami cara melakukan unit testing menggunakan `pytest` serta pemeriksaan tipe data dengan `mypy`.

### 2. Kendala yang dihadapi
Kendala yang dialami yaitu menyesuaikan anotasi tipe data agar memenuhi kriteria pemeriksaan `mypy`. Selain itu, sempat terjadi kesalahan struktur folder pada GitHub Actions karena meletakkan beberapa berkas tugas di luar direktori pribadi.

### 3. Solusi
Solusi yang dilakukan adalah merevisi anotasi tipe data pada fungsi yang bermasalah hingga lolos pengecekan `mypy`, serta merapikan dan memindahkan seluruh berkas tugas ke dalam folder pribadi agar pemeriksaan otomatis berjalan lancar.
