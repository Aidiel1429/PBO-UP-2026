# AI Usage

## Penggunaan AI pada P02

Pada pengerjaan P02, saya menggunakan AI sebagai bantuan untuk memahami langkah praktikum dan memperbaiki kesalahan kode.

Bantuan AI digunakan untuk:
- Memahami struktur kelas `Penyewa` dan `AlatTani`.
- Membantu memperbaiki kesalahan pada `main.py`.
- Membantu memahami error dari `periksa_pbo.py`.
- Membantu memperbaiki masalah `mypy` dan package `src`.
- Membantu memahami penggunaan `pytest`, `mypy`, dan Ruff.

Kode tetap saya jalankan dan periksa sendiri melalui terminal. Hasil akhir saya validasi menggunakan pemeriksa PBO, `pytest`, `mypy`, dan Ruff.
