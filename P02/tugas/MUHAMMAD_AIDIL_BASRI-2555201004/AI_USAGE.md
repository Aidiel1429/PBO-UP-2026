# AI Usage

Dalam praktikum P02 saya menggunakan ChatGPT sebagai bantuan belajar dan pendamping saat mengerjakan praktikum.

## Bentuk penggunaan

AI digunakan untuk:
- membantu memahami konsep class, object, constructor, method, dan `self`;
- membantu memahami langkah-langkah praktikum P02;
- membantu membuat contoh implementasi kelas `Penyewa`, `AlatTani`, dan `Petugas`;
- membantu membuat contoh fungsi pengujian menggunakan `pytest`;
- membantu memahami error yang muncul saat menjalankan program;
- membantu memahami hasil pemeriksaan `periksa_pbo.py`, `mypy`, dan `pytest`;
- membantu memahami langkah Git seperti commit, branch, dan push.

Kode program tetap saya jalankan dan periksa sendiri di lingkungan praktikum. Saya memahami kembali kode dan langkah yang digunakan sebelum memasukkannya ke repository.
