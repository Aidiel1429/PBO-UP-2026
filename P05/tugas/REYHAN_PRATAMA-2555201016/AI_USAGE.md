# AI Usage

Dalam pengerjaan tugas praktikum P05, saya menggunakan ChatGPT sebagai alat bantu untuk memahami materi dan menyelesaikan beberapa kendala selama pengerjaan.

Bentuk penggunaan AI:
1. Membantu memahami konsep asosiasi, agregasi, dan komposisi.
2. Membantu memeriksa dan memperbaiki kode program Python.
3. Membantu menyusun dan memperbaiki pengujian menggunakan pytest.
4. Membantu memahami pesan kesalahan dari mypy dan ruff.
5. Membantu memeriksa kesesuaian diagram kelas dan dokumentasi tugas.

Seluruh kode dan hasil pengerjaan diperiksa serta dijalankan kembali sebelum dikumpulkan. Saya bertanggung jawab atas hasil akhir tugas yang dikumpulkan.
