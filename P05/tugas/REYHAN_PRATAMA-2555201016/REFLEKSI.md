# Refleksi Praktikum P05

Pada praktikum P05, saya mengembangkan program SIPALA (Sistem Informasi Penyewaan Alat Pertanian) menggunakan konsep Pemrograman Berorientasi Objek.

Melalui praktikum ini, saya mempelajari penerapan lima kelas, yaitu Penyewa, Alamat, AlatTani, BarisSewa, dan Sewa. Saya juga memahami hubungan antarobjek melalui konsep asosiasi, agregasi, dan komposisi.

Selama pengerjaan, saya menemukan beberapa kendala dalam menyusun hubungan antarkelas, melakukan validasi data, dan memastikan perhitungan biaya penyewaan berjalan dengan benar. Saya mengatasinya dengan memeriksa kembali kode dan menjalankan pengujian menggunakan pytest, mypy, dan ruff.

Dari praktikum ini, saya menjadi lebih memahami cara merancang program yang terstruktur, menerapkan konsep PBO, serta melakukan pengujian untuk memastikan program berjalan sesuai kebutuhan.

Ke depannya, saya perlu lebih teliti dalam merancang hubungan antarkelas dan menguji setiap fitur sebelum program dikumpulkan.
