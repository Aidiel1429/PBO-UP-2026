# Dokumentasi Penggunaan AI (AI Usage)

Dalam pengembangan tugas modul P05 ini, asisten kecerdasan buatan (AI) digunakan sebagai alat bantu untuk:
1. Memverifikasi struktur direktori repositori agar sesuai dengan konvensi pengumpulan tugas modul sebelumnya (P01-P04).
2. Menyusun kerangka kode dasar untuk objek nilai seperti `periode_tugas.py` dan kelas entitas `petugas.py`.
3. Memberikan panduan langkah-langkah navigasi terminal PowerShell dan pengelolaan berkas di dalam VS Code.

Seluruh logika kode utama, penyesuaian, serta pengujian (*testing*) tetap ditinjau, dipahami, dan divalidasi secara mandiri.
