# Refleksi Modul P05 - Pemrograman Berorientasi Objek

Pada modul P05 ini, saya mempelajari penerapan konsep Pemrograman Berorientasi Objek (PBO) lanjutan, khususnya dalam hal perancangan struktur data yang rapi menggunakan objek nilai (*value object*) seperti `PeriodeTugas` dengan validasi berbasis tipe data tanggal, serta pemodelan entitas pendukung seperti `Petugas`. 

Penyusunan kode ini melatih saya untuk memastikan hubungan antar-kelas (komposisi dan asosiasi) tetap konsisten, teruji melalui unit test, serta mengikuti konvensi direktori proyek yang telah ditetapkan secara modular.
