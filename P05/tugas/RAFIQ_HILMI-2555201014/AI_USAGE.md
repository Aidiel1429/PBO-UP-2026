# Catatan Penggunaan Asisten AI

## Pertemuan 1
- Menggunakan ChatGPT untuk membantu memahami konsep dasar Python dan pemrograman berorientasi objek (PBO), memahami pelanggaran pada kode, serta mempelajari cara menggunakan pemeriksa kode, mypy, pytest, dan Git/GitHub.
- Saran AI ditinjau dan pemeriksaan program dijalankan secara langsung.

## Pertemuan 2
- Menggunakan ChatGPT untuk membantu memahami class, object, constructor, method, dan parameter self, termasuk memahami kesalahan TypeError akibat self yang belum sesuai.
- AI membantu menyusun dan memeriksa class Petugas, membuat pengujian, memahami hasil periksa_pbo.py, mypy, dan pytest, serta membantu memahami materi LKM-02.
- Pengujian program dijalankan secara langsung.

## Pertemuan 3
- Menggunakan ChatGPT untuk membantu memahami enkapsulasi, property hanya-baca, setter dengan validasi, dan penggunaan frozen pada NomorPegawai.
- AI membantu menyusun dan memeriksa kode Petugas dan NomorPegawai, membuat pengujian menggunakan pytest.raises, serta memahami dan memperbaiki hasil pemeriksaan periksa_pbo.py, mypy, pytest, dan Ruff.
- Hasil kode diperiksa menggunakan alat pengujian yang tersedia.

## Pertemuan 4
- Menggunakan ChatGPT untuk membantu memahami panduan praktikum dan ketentuan tugas individu, menyusun class Kios untuk produk UMKM, serta menerapkan konstanta Final, pencacah jumlah produk, classmethod sebagai constructor alternatif, dan staticmethod untuk validasi harga jual.
- AI membantu menyusun pengujian untuk data valid dan tidak valid, merapikan kode, serta memahami dan memperbaiki hasil pemeriksaan Ruff, mypy, pytest, dan periksa_pbo.py dengan profil P04.
- Pengujian dan pemeriksaan kode dijalankan secara langsung untuk memastikan hasilnya sesuai dengan ketentuan praktikum.

## Pertemuan 5
Menggunakan ChatGPT untuk membantu memahami hubungan antarclass, yaitu association, aggregation, dan composition, serta penerapannya pada class Penyewa, Alamat, Sewa, BarisSewa, dan AlatTani.

AI membantu menyusun dan memeriksa class BarisSewa dan Sewa, memahami penyimpanan tarif saat transaksi, membatasi perubahan data internal menggunakan tuple, serta membuat pengujian menggunakan pytest.

AI membantu memahami contoh kesalahan tanpa salinan data dan komposisi yang bocor, serta membantu membuat dan memeriksa diagram kelas.

Hasil kode diperiksa secara langsung menggunakan periksa_pbo.py dengan profil P05, mypy, pytest, dan Ruff.
