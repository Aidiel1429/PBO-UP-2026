# Pertemuan 4

Menggunakan asisten AI (ChatGPT) untuk membantu memahami dan menyelesaikan praktikum P04.

Bantuan meliputi penerapan konstanta kelas (Final), atribut kelas dan atribut instance, metode staticmethod, classmethod, serta konstruktor alternatif pada kelas AlatTani.

Menggunakan ChatGPT untuk membantu memperbaiki kode pada file alat_tani.py, penyewa.py, dan petugas.py agar sesuai dengan aturan Ruff.

Memeriksa hasil pengerjaan menggunakan ruff, pytest, mypy, dan pemeriksa disiplin PBO dengan profil P04.

Seluruh kode diperiksa dan dijalankan secara mandiri untuk memastikan hasil pengujian berhasil.
