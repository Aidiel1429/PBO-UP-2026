# Catatan Penggunaan Asisten AI

## Pertemuan 4 — P04

Pada pengerjaan praktikum P04, saya menggunakan ChatGPT sebagai
asisten untuk membantu memahami materi dan menyelesaikan tugas.

Bentuk bantuan yang digunakan:

1. Memahami konsep konstanta tingkat kelas, class attribute,
   `@classmethod`, dan `@staticmethod`.
2. Mendapatkan arahan dalam mengembangkan kelas `AlatTani`.
3. Membantu memahami validasi tarif, format rupiah, pengolahan
   data CSV, dan perhitungan denda keterlambatan.
4. Membantu menyusun dan memeriksa pengujian menggunakan pytest.
5. Membantu menganalisis serta memperbaiki kesalahan encoding
   BOM pada file Python.
6. Membantu menjalankan pemeriksaan disiplin PBO, mypy,
   dan pytest.
7. Memberikan panduan penggunaan Git untuk commit dan
   persiapan pengumpulan tugas.

Seluruh kode dan hasil pengerjaan diperiksa serta diuji kembali
oleh saya menggunakan Python dan perangkat pengembangan yang
digunakan dalam praktikum.

AI digunakan sebagai alat bantu pembelajaran, bukan sebagai
pengganti pemahaman dan tanggung jawab saya terhadap hasil tugas.
